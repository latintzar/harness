# Project ownership

Agent workspace is the reusable software framework originally called the Vitrina Harness, extracted from Rocoto's business software. Peter Neyra directed that this framework belongs with Vitrina.

This public source candidate contains Peter's original framework code under MIT, its required dependencies and a minimal bare vertical. Existing runtime/customer state, accounts and provider grants retain their original owners. Third-party software and assets keep their own notices in THIRD_PARTY.md. Private historical source and operating records remain preserved separately.
