# Bare vertical

The bare vertical supplies the Organization conversation and a general Agent class over the shared harness. Its manifest selects optional communication capabilities, declares the workspace-reader role and gives Organization a complete setup recipe. Shared mechanics own its records, files, connections, jobs, displays and page shell.

Run with `ROCOTO_VERTICAL=bare python3 harness/run.py server --state /absolute/private/state`. The artifact and actual backend lifecycle are tested with the retail folder and dependencies absent. Managed execution uses the current workspace's application key and funded provider pool.

Read [the SDK](../../sdk/README.md) for the manifest and extension contract, or [the bare deployment runbook](../../../README.md#run-the-bare-workspace) for its prepared public target.
