# Rocoto UI kit adapter

This folder contains a static rendering of the installed Rocoto app kit. It is generated by `scripts/kit-build.mjs`; the source app is selected with `ROCOTO_KIT_APP` (default `/home/peter/rocoto-repo/app`).

- **Theme:** the actual `app/src/rocoto-theme.ts` factory runs against installed BaseUI. Its resolved colours, spacing, radii, typography, motion and elevation become `--rocoto-<section>-<token>` CSS variables. Original token names and values are retained.
- **Buttons:** BaseUI's `Button` renders through ReactDOMServer and StyletronServer. Its generated CSS is exported under `.rocoto-kit-icon-button` (tertiary compact circle), `.rocoto-kit-button` (tertiary compact pill), and `.rocoto-kit-secondary-button` (secondary compact pill). These remain ordinary semantic buttons in the player. Contextual foreground/background styling can adapt them to the video surface.
- **Icons:** `lucide.svg` contains paths rendered directly from the installed Lucide React components. The SVG `symbol` IDs are kebab-case (`play`, `chevron-right`, `volume-2`); the full list is in `provenance.json`.
- **Typography:** the app's installed Inter Latin 400, 500, 600 and 700 fonts are served locally. Resolved typography classes are `.rocoto-type-LabelMedium`, `.rocoto-type-ParagraphSmall`, etc.

Load `kit/rocoto-kit.css` before the player stylesheet. An icon uses a normal SVG with `viewBox="0 0 24 24"`, `fill="none"`, `stroke="currentColor"`, `stroke-width="2"`, rounded line caps/joins, and `<use href="kit/lucide.svg#play">`.

The adapter does not introduce a client React runtime. It reuses the real kit's resolved tokens, generated button rules, icon shapes and fonts. The player owns its data, interactions and video composition. Overland/TwelveLabs-inspired trail lighting is a player visual treatment, not a fabricated kit component.

`provenance.json` records dependency versions and the theme source SHA-256. Licenses for BaseUI, Lucide and Inter are included. BaseUI's npm artifact omits its LICENSE; `LICENSE-baseui.txt` is preserved from `https://raw.githubusercontent.com/uber/baseweb/master/LICENSE`.
